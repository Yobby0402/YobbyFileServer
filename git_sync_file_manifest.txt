# 若你在本机命令行操作其它目录仍报错，可对该仓库执行：
#   git config --global --add safe.directory "该仓库绝对路径"

## 附录 B：同一 GitHub 用户使用两把 SSH 密钥「无缝」切换
# 两把公钥都添加到同一 GitHub 账户后，服务端任意一把都能认证。
# 若本机 ssh-agent 多把钥匙导致连错、或需固定用某把钥匙连某远程：
# 编辑 ~/.ssh/config（Windows：C:\Users\<你>\.ssh\config），例如：
#
#   Host github.com
#     HostName github.com
#     User git
#     IdentityFile ~/.ssh/id_ed25519_key_a
#     IdentitiesOnly yes
#
#   Host github-b.com
#     HostName github.com
#     User git
#     IdentityFile ~/.ssh/id_ed25519_key_b
#     IdentitiesOnly yes
#
# 远程地址与 Host 对齐：
#   git remote set-url origin git@github-b.com:Yobby0402/YobbyFileServer.git
# 用哪把钥匙就改成对应的 Host（github.com 或 github-b.com）。
