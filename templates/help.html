快速上手 3 步完成部署与访问

步骤 1 · 启动服务

  • 图形界面（推荐）： 双击 YobboyFileServer.exe → 点击“启动服务器” → 复制或扫码界面上方地址。
  • 命令行： python main.py 即可启动（确保安装依赖）。
  • 界面显示绿色状态代表服务已启动；支持最小化到托盘后台运行。

步骤 2 · 登录系统

  • 首次访问会自动跳转至登录页面，默认密码：password。
  • 建议立即通过 文件 → 设置 或编辑 config.ini 更改密码。
安全提示： 团队内共享部署时，建议为不同环境设置不同密码并记录访问日志。

步骤 3 · 选择功能

登录成功后进入选择界面，可一键打开：

  • 文件浏览器、Draw.io 编辑器、Markdown 预览
  • ToDo 时间轴中心、串口调试助手、3D 模型查看、分享管理等

产品对比工具

文件浏览器 预览 + 编辑 + 上传

  • Markdown：支持表格、任务列表、脚注，图片相对路径自动修正。
  • 文档：PDF 在线预览；Office 文件可下载。
  • 多媒体：MP3/WAV/FLAC、MP4/AVI/WEBM 直接播放。

常用操作

  • 上传/新建文件夹/新建文件或 Draw.io 图表。

  • 支持按类型过滤（图片/代码/文档等）。
  • 面包屑导航快速回到上级目录。

服务器根目录设置

  • GUI：文件 → 设置 → 选择根目录 → 保存。
  • Web：访问 /set_root（需管理员密码）。
  • 配置文件：编辑 config.ini 中的 root_dir 并重启。
[settings] root_dir = C:\your\workspace password = password admin_password = admin123 close_to_tray = true port = 5000

串口调试助手 本地 + 远程 + 持续日志

本地串口模式

  • 基于 Web Serial API，需要 Chrome / Edge / Opera 等 Chromium 浏览器。
  • 首次授权后可直接选择串口，支持气泡模式与终端模式切换。
  • 内置快捷键（Ctrl+C / Ctrl+D / Tab 等）与定时发送。
浏览器限制：必须在 HTTPS 或 localhost 下使用 Web Serial 功能；非安全上下文请切换到远程模式。

远程串口模式

  • 通过 Socket.IO 连接服务器串口，可远程监控与发送命令。
  • 支持多监听器，调试过程不会影响后台日志记录。
  • 断开连接前自动保存当前会话日志，便于追踪历史。

持续日志捕获

  • 在“持续日志”面板选择串口和参数，点击“开启持续日志”即可后台写入 JSONL。
  • 日志可以随时载入到当前界面，与实时数据一起查看，支持增量加载。
  • 可随时停止日志捕获；日志保存在 logs/serial_capture/<port>/YYYY-MM-DD.jsonl。
  • API：POST /api/serial/capture/start、/stop、/status、/log/<port>。

参数排序

配置与部署 多种方式可选

安装方式

  • 源码部署：git clone → pip install -r requirements.txt → python main.py。

安全与隐私 离线部署最佳实践

部署建议

  • 推荐放置在内网/团队局域网环境；避免暴露公网上。
  • 首启后立即修改默认密码，必要时开启双重密码。
  • 定期检查 logs 目录，记录访问行为。

权限控制

  • 所有 Web 功能均需登录才能访问。
  • 管理员密码用于修改根目录、访问帮助等敏感操作。
  • 内置路径安全检查，防止目录遍历。

常见问题 FAQ

服务器无法启动？

  • 端口是否被占用（默认5000）？可在GUI设置中修改端口，或编辑 config.ini 中的 port。
  • 检查日志窗口或 logs 目录获取错误栈。
  • Windows 上请确保未被防火墙阻止。

浏览器无法访问？

  • 确认服务器已启动并显示访问地址。
  • 客户端与服务器需在同一网段。
  • 防火墙需允许服务器端口（默认5000），或使用 localhost 访问。

文件预览异常？

  • 视频/音频需浏览器支持对应编码（推荐 MP4/H.264, MP3）。
  • PDF 预览需要浏览器内置阅读器（Chromium/Firefox 默认支持）。
  • Markdown 图片需位于与文档同一根目录。

还有其他问题？

欢迎在 GitHub Issues 或团队内部文档提出反馈，也可以在界面右上角使用“反馈”入口联系我们。

使用帮助 - Yobboy文件服务器

📖 Yobboy文件服务器使用帮助

欢迎使用Yobboy文件服务器！本指南将帮助您快速上手。

快速开始

1. 启动服务器

方式一：使用图形界面（推荐）

  • 双击运行 YobboyFileServer.exe
  • 点击 "启动服务器" 按钮
  • 服务器启动后，界面会显示访问地址
  • 在浏览器中打开显示的任何一个地址即可访问
💡 提示：

图形界面提供了菜单栏，可以方便地访问各种功能：

  • 文件菜单：设置服务器根目录和密码、退出程序
  • 窗口菜单：最小化到系统托盘（服务器会在后台继续运行）
  • 帮助菜单：查看使用帮助、关于信息

2. 登录系统

  • 首次访问会进入登录页面
  • 输入密码（默认密码：ats123）
  • 登录成功后会进入功能选择页面

3. 选择功能

登录后您可以选择以下功能：

📁 文件浏览器

浏览、预览和下载服务器上的文件。支持多种文件格式查看，全离线模式，仅局域网内访问。

📊 Draw.io 编辑器

创建和编辑流程图、架构图等。支持本地文件上传和服务器保存，全离线模式，不依赖第三方服务。

文件浏览器功能

支持的文件类型

  • 图片文件：JPG, PNG, GIF, BMP, SVG, WebP - 直接在线预览
  • Markdown文件：MD, MARKDOWN - 渲染后显示，支持图片相对路径
  • PDF文件：直接在浏览器中预览
  • 视频文件：MP4, AVI, MOV, WMV - 在线播放
  • 代码文件：Python, JavaScript, HTML, CSS等 - 语法高亮显示
  • Draw.io文件：DRAWIO, DIO, DIAGRAM, XML - 在线预览和编辑

主要操作

  • 浏览文件：点击文件夹可以进入该目录
  • 预览文件：点击文件名在弹窗中预览文件内容
  • 下载文件：点击下载按钮将文件保存到本地
  • 返回上级：使用面包屑导航快速跳转到上级目录

服务器设置

如果需要更改服务器配置（根目录和密码）：

  • 图形界面：点击菜单栏 "文件 → 设置"，在弹出的设置对话框中：
    • 点击"浏览"按钮选择新的根目录
    • 在密码框中输入新密码
    • 点击"保存设置"按钮
    • 如果服务器正在运行，会自动先停止服务器
  • Web界面：访问 /set_root 路径可以设置根目录
  • 配置文件：直接编辑 config.ini 文件，然后重启服务器
  • 更改设置后需要重启服务器使配置生效

Draw.io 编辑器功能

主要特性

  • 完全离线：无需连接外部服务，所有功能均在本地运行
  • 丰富的图形库：流程图、UML图、网络图、思维导图等
  • 实时保存：可以将图表保存到服务器或导出到本地
  • 多种导出格式：支持PNG、JPG、SVG、PDF等格式导出

基本操作

  • 创建新图表：进入Draw.io编辑器后，从左侧图形库拖拽元素到画布
  • 保存图表：使用 Ctrl+S 或点击保存按钮将图表保存到服务器
  • 打开现有图表：从文件浏览器中点击.drawio文件即可编辑
  • 导出图表：点击 文件 → 导出为 选择导出格式
💡 提示：

Draw.io编辑器支持快捷键操作，常用的有：Ctrl+C 复制，Ctrl+V 粘贴，Ctrl+Z 撤销，Delete 删除选中元素。

配置说明

配置文件位置

配置文件 config.ini 保存在以下位置：

  • 优先：程序运行目录
  • 备选：用户主目录下的 .yobboy_file_server 文件夹

配置项说明

[settings]
root_dir = C:\your\path\here # 文件浏览器根目录
password = ats123 # 登录密码

修改配置的三种方式

方式一：使用GUI设置界面（推荐）

  • 在图形界面中点击菜单栏 "文件 → 设置"
  • 在设置对话框中修改根目录和密码
  • 点击"保存设置"即可，无需手动重启
  • 如果服务器正在运行，系统会自动先停止服务器

方式二：手动编辑配置文件

  • 找到并打开 config.ini 文件
  • 修改 root_dir 和 password 的值
  • 保存文件后重启服务器使更改生效

方式三：Web界面设置

  • 登录后访问 /set_root 路径设置根目录
  • 修改密码需要编辑配置文件

安全与隐私

  • 局域网访问：服务器仅在局域网内可访问，不暴露到公网
  • 密码保护：所有功能均需要登录后才能使用
  • 离线运行：完全离线运行，不会向外部发送任何数据
  • 访问记录：所有访问记录保存在 logs 目录中，可随时查询
  • 路径安全：系统会自动防止路径遍历攻击，确保只能访问根目录下的文件
⚠️ 注意：

请妥善保管登录密码，不要在不受信任的设备上使用。如果怀疑密码泄露，请及时通过GUI设置界面或编辑配置文件修改密码。

常见问题

Q: 服务器启动失败怎么办？

A: 请检查以下几点：

  • 端口5000是否被其他程序占用
  • 防火墙是否阻止了程序运行
  • 查看日志文件获取详细错误信息

Q: 无法访问服务器？

A: 请确认：

  • 服务器是否已成功启动（查看GUI界面状态）
  • 访问地址是否正确（使用GUI界面显示的地址）
  • 客户端和服务器在同一局域网内
  • 防火墙未阻止端口5000

Q: 文件预览不正常？

A: 不同文件类型的预览要求：

  • PDF文件需要浏览器支持PDF预览
  • 视频文件需要浏览器支持对应的编码格式
  • Markdown文件中的相对路径图片需要与MD文件在同一根目录下

Q: 如何在其他设备访问？

A: 操作步骤：

  • 确保所有设备在同一局域网内（连接同一WiFi或路由器）
  • 在GUI界面查看服务器IP地址
  • 在其他设备的浏览器中输入 http://服务器IP:5000
  • 输入登录密码即可访问

Q: 如何修改服务器根目录和密码？

A: 最简单的方法：

  • 在GUI界面点击菜单栏 "文件 → 设置"
  • 在弹出的设置对话框中修改根目录和密码
  • 点击"保存设置"按钮即可
  • 如果服务器正在运行，会自动先停止
  • 保存后可以重新启动服务器使用新配置

Q: 如何访问帮助文档？

A: 有两种方式：

  • GUI界面：点击菜单栏 "帮助 → 使用帮助"，系统会自动打开浏览器显示帮助页面（如果服务器未运行会先启动）
  • Web界面：在选择页面底部点击"使用帮助"链接，或直接访问 /help 路径

Q: GUI窗口关闭后服务器会停止吗？

A: 取决于操作方式：

  • 最小化到托盘：点击菜单栏 "窗口 → 最小化到托盘"，窗口隐藏但服务器继续运行
  • 关闭窗口：直接关闭窗口会提示是否退出，服务器会停止
  • 托盘图标：双击系统托盘图标可以重新显示窗口
