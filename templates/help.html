快速上手 3 步完成部署与访问

步骤 1 · 启动服务

  • 图形界面（推荐）： 双击 YobboyFileServer.exe → 点击“启动服务器” → 复制或扫码界面上方地址。
  • 命令行： python main.py 即可启动（确保安装依赖）。
  • 界面显示绿色状态代表服务已启动；支持最小化到托盘后台运行。

步骤 2 · 登录系统

  • 首次访问会自动跳转至登录页面，默认密码：password。
  • 建议立即通过 文件 → 设置 或编辑 config.ini 更改密码。
安全提示： 团队内共享部署时，建议为不同环境设置不同密码并记录访问日志。

步骤 3 · 选择功能

登录成功后进入选择界面，可一键打开：

  • 文件浏览器、Draw.io 编辑器、Markdown 预览
  • ToDo 时间轴中心、串口调试助手、3D 模型查看、分享管理等

产品对比工具

文件浏览器 预览 + 编辑 + 上传

支持的预览类型

  • 图片：JPG/PNG/GIF/SVG/WebP 等，可全屏灯箱。
  • Markdown：支持表格、任务列表、脚注，图片相对路径自动修正。
  • 文档：PDF 在线预览；Office 文件可下载。
  • 多媒体：MP3/WAV/FLAC、MP4/AVI/WEBM 直接播放。
  • 代码：100+ 语言语法高亮，支持 Ctrl+S 保存。
  • 3D 模型：GLTF/GLB/OBJ/STL，Three.js 离线渲染。

常用操作

  • 上传/新建文件夹/新建文件或 Draw.io 图表。
  • 批量选择后下载或删除；支持键盘快捷键。
  • 支持按类型过滤（图片/代码/文档等）。
  • 面包屑导航快速回到上级目录。

服务器根目录设置

  • GUI：文件 → 设置 → 选择根目录 → 保存。
  • Web：访问 /set_root（需管理员密码）。
  • 配置文件：编辑 config.ini 中的 root_dir 并重启。
[settings] root_dir = C:\your\workspace password = password admin_password = admin123 close_to_tray = true port = 5000

Git版本控制集成 仓库管理 + 在线编辑

启用与配置

  • 启用Git功能：在GUI界面点击 "文件 → 设置"，勾选"启用Git功能"。
  • 设置Git工作目录：选择Git工作目录，系统会扫描该目录下的所有Git仓库。
  • 配置Git服务器：点击"管理Git服务器配置"按钮，添加Git服务器信息（SSH密钥、服务器地址、认证方式等）。
  • 配置外部软件：设置外部软件路径（如VSCode的code.exe），用于打开仓库。
  • 保存并重启：保存设置后需要重启服务器才能使配置生效。
安全提示：Git服务器配置（SSH密钥、服务器地址等）仅在PyQt5 GUI中设置，不会在Web界面显示，防止敏感信息泄露。

Git视图与仓库列表

  • 切换Git视图：在文件浏览器顶部，点击"Git"按钮切换到Git视图（仅当启用Git功能时显示）。
  • 仓库列表：系统会自动扫描Git工作目录，显示所有Git仓库及其状态。
  • 仓库状态：每个仓库显示分支名称、远程地址、工作区状态（干净/有修改/有未提交更改）。
  • 进入仓库：点击仓库名称或图标进入仓库，可以浏览文件、编辑文件、执行Git操作。
  • 克隆仓库：点击"克隆仓库"按钮，可以从远程服务器克隆仓库到本地。

克隆仓库

  • 选择仓库：在"选择仓库"标签页，搜索并选择要克隆的远程仓库（支持Gitolite服务器的info命令）。
  • 手动输入：在"手动输入"标签页，可以输入仓库路径（如 project/repo）或完整URL（如 git@hostname:project/repo.git）。
  • 克隆到本地：系统会自动将仓库克隆到Git工作目录，克隆过程中显示实时进度。
  • 自动清理：如果目标目录已存在，系统会尝试自动清理后再克隆。

拉取 (Pull)

  • 作用：从远程仓库下载最新的更改到本地仓库。
  • 使用场景：
    • 开始工作前，获取远程的最新代码
    • 多人协作时，同步其他人的更改
    • 在其他地方修改了代码，需要同步到当前工作区
  • 注意事项：如果有未提交的本地更改，拉取可能会产生冲突，需要先处理冲突。

推送 (Push)

  • 作用：将本地的提交上传到远程仓库。
  • 使用场景：
    • 完成本地修改并提交后，推送到远程仓库
    • 分享你的代码更改给团队成员
    • 备份本地代码到远程仓库
  • 注意事项：
    • 推送前必须先提交（Commit）更改，并填写提交信息
    • 如果远程有新的提交，需要先拉取并合并
    • 推送只会推送已提交的更改，未提交的更改不会推送

同步 (Sync)

  • 作用：先拉取远程更改，再推送本地更改。相当于执行"拉取"+"推送"。
  • 使用场景：
    • 确保本地和远程仓库完全同步
    • 在推送前自动获取远程最新更改
    • 快速同步本地和远程仓库
  • 注意事项：同步会先拉取，如果有冲突需要先解决冲突，然后才能推送。

提交 (Commit)

  • 作用：将工作区的更改保存到本地仓库，并添加提交信息说明。
  • 使用场景：
    • 完成一部分功能后，保存更改
    • 修复bug后，记录修复内容
    • 准备推送前，必须先提交更改
  • 提交信息：应该清晰描述本次更改的内容，便于后续查看历史记录。
  • 注意事项：提交只保存到本地，不会上传到远程。需要推送才能将更改上传到远程仓库。

文件编辑与预览

  • 在线编辑：进入仓库后，点击文件可以预览，点击"编辑文件"按钮可以编辑文件。
  • 语法高亮：代码文件支持100+种语言的语法高亮（使用CodeMirror）。
  • Markdown分屏：Markdown文件支持分屏预览模式，左侧编辑右侧实时预览。
  • 保存更改：编辑完成后点击"保存"按钮，更改会保存到本地文件系统。
  • 状态检测：保存后系统会自动检测文件状态（修改、暂存、未跟踪），并更新UI显示。
  • 提交更改：编辑并保存后，需要使用"提交"按钮将更改提交到Git仓库。

历史与分支管理

  • 查看历史：点击"历史"按钮可以查看仓库的提交历史记录，包括提交信息、作者、时间等。
  • 分支管理：在仓库操作栏中，可以查看当前分支，并切换到其他分支。
  • 打Tag：点击"打Tag"按钮可以为当前提交创建标签，通常用于标记版本（如 v1.0.0）。
  • 状态监控：系统每30秒自动刷新仓库状态，显示最新的分支、远程地址、工作区状态。

仓库管理工具

  • 删除仓库：在仓库列表中，点击"删除"按钮可以删除本地仓库（需要确认）。
  • 打开文件浏览器：点击"打开文件浏览器"按钮可以在系统文件浏览器中打开仓库目录（仅限本机访问）。
  • 用外部软件打开：点击"用外部软件打开"按钮可以使用配置的外部软件（如VSCode）打开仓库（仅限本机访问）。
  • 调试工具：点击"调试"按钮可以执行Git命令并查看输出，用于排查问题。
  • 帮助页面：点击"帮助"按钮可以查看Git操作的详细说明和使用建议。

工作流程建议

  1. 开始工作前：先执行"拉取"，获取最新代码
  2. 修改文件：在仓库中编辑文件并保存
  3. 提交更改：填写提交信息并提交更改到本地仓库
  4. 推送到远程：执行"推送"或"同步"将更改上传到远程仓库

ToDo 任务管理系统 项目进度可视化

搜索与筛选

  • 支持按项目名称、任务简述、描述搜索。
  • 项目筛选下拉框可选择特定项目或查看全部项目。
  • 支持表格视图、卡片视图和汇报视图三种展示方式。

项目管理

  • 创建、编辑、删除项目，设置项目主题色和描述。
  • 项目表格可折叠展开，显示项目名称、创建时间、任务数、整体进度、项目阶段。
  • 项目描述支持Markdown编辑和预览。
  • 为项目添加外部链接或文件浏览器链接。

任务管理

  • 创建、编辑、删除任务，设置优先级、进度、预计完成时间。
  • 任务支持拖拽排序调整任务顺序。
  • 任务详细描述支持展开/折叠，支持Markdown格式。
  • 评论系统：为任务添加评论，记录进展和补充说明。
  • 更新历史：记录每次任务更新的时间和变更内容。

待完成概览与导出

  • 卡片方式展示待完成任务，按逾期/今日/即将到期分类。
  • 支持灵活配置的Excel导出，包括时间范围、列选择等。
  • 汇报视图：选择展示到汇报页的项目和任务，展示所有任务的简述。
  • 汇报表格Excel导出：一键导出汇报视图为Excel，自动调整列宽和行高，支持筛选功能。

会议记录（笔记）

  • 独立的笔记管理功能，支持按日期创建和管理笔记。
  • Markdown编辑和实时预览（左右分屏模式），支持语法高亮。
  • 笔记列表支持搜索、排序和筛选：按日期或更新时间排序，搜索笔记内容自动匹配。
  • 历史笔记默认折叠，点击展开查看，支持编辑和删除。
  • 笔记保存在独立文件中，与项目描述分离管理。

本地 AI 与 MCP 可追踪、可确认、可中断

AI 对话能力

  • 支持 通用 / 知识库 / 代办 三种模式，支持流式输出。
  • 对话生成期间提供明显“生成中”状态；支持手动停止（中断）当前生成。
  • 支持“强制解析为变更”用于将自然语言请求直接转为待办变更提案。

MCP 工具接入

  • 本地 AI 通过 MCP 桥接调用后端工具（Todo、知识库、Draw.io 校验与修复）。
  • 界面提供 MCP 调用记录，可查看调用了什么工具及结果状态。
  • 支持本地调用与外部客户端调用并存，方便后续替换模型或扩展客户端。

ToDo 变更确认与防误操作

  • AI 生成待办变更后需二次确认再执行，支持可视化编辑操作项。
  • 支持“校验 JSON”进行二次检查；校验通过后再应用，降低误改风险。
  • 待确认操作会持久化保存；关闭弹窗或刷新页面后仍可恢复并继续执行。
  • 有待执行操作时，AI 按钮会红色闪烁提醒。

Draw.io AI 自修复流程

  • 默认由模型输出 **yobboy-flow** 类 Mermaid 文本（可带坐标），服务端转为可编辑 mxfile；可在设置中切回直接输出 XML。内置 `drawio_text_dsl_to_xml`、`drawio_validate_xml`、`drawio_summarize_xml`、`drawio_diff_summary`、`drawio_repair_xml` 工具链。
  • 生成失败会自动基于校验问题进行修复重试，并展示重试进度。
  • 最终输出前执行收口校验，减少“中途可过、最终失败”的 XML 解析问题。
  • 支持布局问题检测（重叠/越界），辅助定位图形可读性问题。

串口调试助手 本地 + 远程 + 持续日志

本地串口模式

  • 基于 Web Serial API，需要 Chrome / Edge / Opera 等 Chromium 浏览器。
  • 首次授权后可直接选择串口，支持气泡模式与终端模式切换。
  • 内置快捷键（Ctrl+C / Ctrl+D / Tab 等）与定时发送。
浏览器限制：必须在 HTTPS 或 localhost 下使用 Web Serial 功能；非安全上下文请切换到远程模式。 现在服务器设置支持兼容模式，可保留主站 HTTP，并为串口助手单独开启 HTTPS 入口。

远程串口模式

  • 通过 Socket.IO 连接服务器串口或浏览器共享串口，可远程监控与发送命令。
  • 所有客户端共享同一收发流，支持多监听器同时查看、同时发送并实时同步。
  • 浏览器无需安装额外程序；共享端关闭页面后，对应共享串口会自动下线。

持续日志捕获

  • 在“持续日志”面板选择串口和参数，点击“开启持续日志”即可后台写入 JSONL。
  • 日志可以随时载入到当前界面，与实时数据一起查看；默认仅加载最近一段记录，旧记录按需继续读取。
  • 浏览器共享串口断开后对应日志会自动停止；服务器本机串口日志则可由任意后续客户端手动停止。
  • 日志保存在 logs/serial_capture/<port>/YYYY-MM-DD.jsonl。
  • API：POST /api/serial/capture/start、/stop、/status、/log/<port>。

编辑与预览 Draw.io / Markdown / Code

Draw.io 编辑器

  • 完全离线，内置中文界面与完整版图库。
  • 支持 Ctrl+S 保存到服务器，Ctrl+Shift+S 另存为本地。
  • 导出 PNG / SVG / PDF；支持导入外部 draw.io 文件。

Markdown & 代码编辑

  • Markdown-it 渲染引擎，支持表格/脚注/任务列表。
  • CodeMirror 编辑器：行号、折叠、查找替换、快捷键齐全。
  • 自动识别 UTF-8 / GBK 编码，保存前提醒未保存修改。

产品对比工具 参数对比与可视化分析

属性管理

  • 定义产品属性列表，支持通用参数（数值型）和普通属性（文本型）。
  • 为通用参数设置单位、方向（越大越好/越小越好）。
  • 支持拖拽调整属性顺序。

产品管理

  • 添加、编辑、删除产品，设置归属和颜色。
  • 产品按归属自动分类，每个归属可自定义颜色。
  • 为产品添加外部URL、本地文件路径或分享链接。

雷达图对比

  • 基于Chart.js的雷达图，支持多产品叠加对比。
  • 每个参数独立归一化，基于所有产品的最大最小值。
  • 智能分析：自动识别每个参数的最优产品，统计最优项数量。

参数排序

  • 按任意通用参数对产品进行排序，支持升序/降序。
  • 支持创建多个对比文件，分别管理不同的产品对比场景。
  • 所有数据保存在本地JSON文件，支持导入导出。

分享与 3D 功能 演示更轻松

分享链接系统

  • 支持密码、访问次数、过期时间、访问统计。
  • Draw.io / Markdown / 3D 模型 / 视频可嵌入分享页在线预览。
  • 二维码分享，让移动端访问更便捷。

3D 模型查看器

  • Three.js 离线渲染，支持 GLTF/GLB/OBJ/STL。
  • 交互控制：旋转 / 平移 / 缩放 / 线框 / 网格 / 坐标轴。
  • 实时显示顶点数、面数、尺寸等统计信息。

桌面端 GUI 服务管控中心

主窗口

  • 实时显示服务器日志、访问记录、监听地址。
  • 支持一键启动/停止、最小化到托盘、设置根目录与密码。
  • 关闭按钮行为可配置（退出或最小化到托盘）。

设置对话框

  • 修改根目录、登录密码、管理员密码、关闭行为。
  • 保存后自动应用，必要时自动重启服务器。

配置与部署 多种方式可选

安装方式

  • Windows 便携版：下载最新 exe，一键运行，无需额外依赖。
  • 源码部署：git clone → pip install -r requirements.txt → python main.py。
  • 手动打包：运行 pyinstaller YobboyFileServer.spec 生成独立 exe。

配置文件优先级

  • 程序运行目录下的 config.ini。
  • 用户主目录：~/.yobboy_file_server/config.ini。
  • GUI 设置将同步写入配置文件。

安全与隐私 离线部署最佳实践

部署建议

  • 推荐放置在内网/团队局域网环境；避免暴露公网上。
  • 首启后立即修改默认密码，必要时开启双重密码。
  • 定期检查 logs 目录，记录访问行为。

权限控制

  • 所有 Web 功能均需登录才能访问。
  • 管理员密码用于修改根目录、访问帮助等敏感操作。
  • 内置路径安全检查，防止目录遍历。

常见问题 FAQ

服务器无法启动？

  • 端口是否被占用（默认5000）？可在GUI设置中修改端口，或编辑 config.ini 中的 port。
  • 检查日志窗口或 logs 目录获取错误栈。
  • Windows 上请确保未被防火墙阻止。

浏览器无法访问？

  • 确认服务器已启动并显示访问地址。
  • 客户端与服务器需在同一网段。
  • 防火墙需允许服务器端口（默认5000），或使用 localhost 访问。

文件预览异常？

  • 视频/音频需浏览器支持对应编码（推荐 MP4/H.264, MP3）。
  • PDF 预览需要浏览器内置阅读器（Chromium/Firefox 默认支持）。
  • Markdown 图片需位于与文档同一根目录。

常见问题

Q: 服务器启动失败怎么办？

A: 请检查以下几点：

  • 端口5000是否被其他程序占用
  • 防火墙是否阻止了程序运行
  • 查看日志文件获取详细错误信息

Q: 无法访问服务器？

A: 请确认：

  • 服务器是否已成功启动（查看GUI界面状态）
  • 访问地址是否正确（使用GUI界面显示的地址）
  • 客户端和服务器在同一局域网内
  • 防火墙未阻止端口5000

Q: 文件预览不正常？

A: 不同文件类型的预览要求：

  • PDF文件需要浏览器支持PDF预览
  • 视频文件需要浏览器支持对应的编码格式
  • Markdown文件中的相对路径图片需要与MD文件在同一根目录下

Q: 如何在其他设备访问？

A: 操作步骤：

  • 确保所有设备在同一局域网内（连接同一WiFi或路由器）
  • 在GUI界面查看服务器IP地址
  • 在其他设备的浏览器中输入 http://服务器IP:5000
  • 输入登录密码即可访问

Q: 如何修改服务器根目录和密码？

A: 最简单的方法：

  • 在GUI界面点击菜单栏 "文件 → 设置"
  • 在弹出的设置对话框中修改根目录和密码
  • 点击"保存设置"按钮即可
  • 如果服务器正在运行，会自动先停止
  • 保存后可以重新启动服务器使用新配置

Q: 如何访问帮助文档？

A: 有两种方式：

  • GUI界面：点击菜单栏 "帮助 → 使用帮助"，系统会自动打开浏览器显示帮助页面（如果服务器未运行会先启动）
  • Web界面：在选择页面底部点击"使用帮助"链接，或直接访问 /help 路径

Q: GUI窗口关闭后服务器会停止吗？

A: 取决于操作方式：

  • 最小化到托盘：点击菜单栏 "窗口 → 最小化到托盘"，窗口隐藏但服务器继续运行
  • 关闭窗口：直接关闭窗口会提示是否退出，服务器会停止
  • 托盘图标：双击系统托盘图标可以重新显示窗口
